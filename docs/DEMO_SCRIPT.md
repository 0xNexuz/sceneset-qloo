# SceneSet — 90-second demo script

## 0:00–0:10 — Hook

“Most city guides start with what is popular. SceneSet starts with what you actually want to feel. Search a scene, compare cities, and see exactly why one wins.”

## 0:10–0:28 — Search

On **Discover**, enter **Afrobeats parties**. Keep Lagos, Accra, and London selected.

“This is not a fixed Burna Boy demo. I can search a genre, mood, cuisine, or cultural scene. SceneSet resolves that language against Qloo’s taste graph.”

Click **Find the best scene**.

## 0:28–0:52 — Compare

“Qloo returned real taste tags and place recommendations for every city. SceneSet runs the same versioned top-three affinity scorer across all markets—no model improvisation.”

Show the winning city, resolved tags, scores, and place shortlist.

## 0:52–1:06 — Truth boundary

Point to the scope card.

“These are real Qloo-grounded place recommendations. SceneSet does not pretend Qloo is a calendar: event dates, tickets, opening hours, and availability are explicitly unverified.”

## 1:06–1:22 — Prove

Open **Taste receipt**.

“Every run is sealed with its inputs, resolved Qloo tags, request fingerprints, candidate IDs, scorer version, decision, and limitations. If the record changes, verification fails.”

## 1:22–1:30 — Close

Open **Evidence**.

“Eight deterministic tests, a credentialed live integration, and one clear promise: search the culture, find the city, prove the recommendation.”
